## About Me

I'm **Blitz**, a software developer who enjoys building things, figuring out how they work, and then making them better. I've been developing software for years, working across multiple languages and paradigms.

**My main interests** revolve around:
- Backend development &amp; APIs
- Systems programming &amp; architecture  
- Developer tooling &amp; automation
- Software architecture &amp; design patterns

I spend a lot of time experimenting with different technologies, building projects, reading source code, debugging weird problems, and turning ideas into working software. I don't build just to collect technologies — I build because there's usually something I want to understand, improve, automate, or create.

## Developer Philosophy

```

01  Build things instead of endlessly planning them.
02  Understand the problem before reaching for a solution.
03  Prefer clear code over clever code.
04  Read the documentation. Then read the source when necessary.
05  Automate repetitive work.
06  Treat bugs as information, not just obstacles.
07  Build small, learn fast, improve continuously.
08  Leave code easier to understand than you found it.

```
