## About

<table>
<tr>
<td width="62%" valign="top">

I'm Blitz, a software developer who enjoys building things, figuring out how they work, and then making them better.

My main interests sit around **backend development, APIs, systems, developer tooling, automation, and software architecture**. I like understanding what happens underneath the interface instead of treating the stack as a black box.

I spend a lot of time experimenting with different technologies, building projects, reading source code, debugging weird problems, and turning ideas into working software.

I don't build just to collect technologies. I build because there's usually something I want to understand, improve, automate, or create.

## Developer Philosophy

<div align="center">

```text
01  Build things instead of endlessly planning them.
02  Understand the problem before reaching for a solution.
03  Prefer clear code over clever code.
04  Read the documentation. Then read the source when necessary.
05  Automate repetitive work.
06  Treat bugs as information, not just obstacles.
07  Build small, learn fast, improve continuously.
08  Leave code easier to understand than you found it.
```
