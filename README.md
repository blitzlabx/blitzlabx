## About

I'm **Blitz**, a software developer who enjoys turning ideas into working software.

**Python is my primary language.** I also work with JavaScript and TypeScript across the web stack, building frontend experiences, backend systems, APIs, bots, and automation tools.

I enjoy understanding how things work end to end: shaping an interface, designing the logic behind it, connecting services, and making the final product feel right.
